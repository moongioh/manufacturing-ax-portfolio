제조 웹 ERP 1인 구축

무엇
자체 소프트웨어가 하나도 없던 18인 제조·화학 중소기업의 웹 ERP를 1인으로 설계·구축·운영 — FastAPI · React · PostgreSQL · Cloud Run, 14개 업무 도메인.
왜
기존 시스템이 실제 업무 흐름을 담지 못해 데이터가 서류·엑셀·수기 장부로 흩어져 있었습니다. 진행 상태가 제때 갱신되지 않아 일이 어디서 멈췄는지 한참 뒤에 드러나는 경우가 잦았고, 축적된 데이터가 없어 BOM·원가는 추정조차 불가능했습니다 — 기능보다 단일 정합 구조가 먼저였습니다.
결과
입사 4주 차 첫 실가동 → 약 2개월에 걸쳐 14개 도메인으로 확장해 실운영 안착. 흩어져 있던 데이터가 하나의 원장으로 통합되고, BOM 분해와 원가율이 매일 자동으로 잡힙니다.

핵심 설계

짓기 전에 도메인 용어·개념·코드 구조를 온톨로지 개념그래프로 먼저 세웠습니다. 사람과 AI 에이전트가 같은 지도를 쓰게 되면서, 승인된 설계 문서 → 구현 → 기계 강제 검증의 사이클로 1인이 두 달에 14개 도메인을 올릴 수 있었습니다. 데이터 쪽은 모든 재고 변동이 단일 게이트(record_movement)를 지나 기록으로 쌓이고 현재고·원장·리포트가 전부 거기서 계산되는 구조 — 뒤늦게 드러나던 진행 상태와 추정조차 못 하던 BOM·원가가 여기서 풀립니다. 그 위에 시멘틱 검색·RAG의 AI 레이어를 얹었습니다. 상세는 AI 레이어·생산 관리 페이지와 아래 워크스루에서 이어집니다.
